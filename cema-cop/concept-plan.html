Cyber & EW Common Operating Picture — Concept Plan

26 October 2026 · Wan

Proposes a Cyber and Electronic Warfare (CEMA) common operating picture for the Malaysian Army, built in four gated phases, with open-source intelligence (OSINT) fused from the start.

Why Cyber & EW first

Cyber and EW together (CEMA) are the best first module: the owning branch already sits in G6, the data depends least on other services, and OSINT is plentiful.

  • Ownership: G6 Cyber can sponsor and run it without waiting on Navy or Air Force feeds.
  • Data on hand: network logs and threat intelligence already exist; public cyber and spectrum OSINT is free.
  • Quick value: exposure monitoring and threat-intel matching show results within weeks.
  • Foundation: the same data platform, access control and audit carry over to later land, maritime and air modules.

Capability

The system runs the same loop for both domains, and its key view links each network asset to the unit and mission it supports, so a cyber event reads as a mission impact.

Architecture

Data moves through five stages, all hosted on-premises or air-gapped, using open-source components so no classified data leaves ATM infrastructure.

  1. Collect — adapters per source; OSINT is pulled on a separate internet-facing segment and transferred inward one way.
  2. Ingest and normalise — a message bus (Kafka or NiFi); common formats: STIX 2.1 for cyber threat data, SigMF for spectrum recordings.
  3. Store — OpenSearch for logs, PostGIS for map data, TimescaleDB for time series, Neo4j for the link graph.
  4. Analyse — Sigma detection rules, anomaly models, threat-intel matching against the asset inventory, and a locally hosted language model for the brief agent.
  5. Present — web interface with role-based access by clearance, case management (TheHive) and an append-only audit log.

Candidate building blocks: Wazuh or Security Onion (SIEM), MISP and OpenCTI (threat intel), TheHive (cases), GNU Radio (spectrum processing), MapLibre and CesiumJS (maps).

Roadmap

Phase 0 can start now; each later phase begins only once its gate is passed.

Phase 0 needs no real data and no network connection, so it carries no security risk and builds the case for Gate 1.

Status and decisions needed

One piece exists today: a script that pulls eight public OSINT feeds. There is no user interface yet; building one is Phase 0.

  • Built: connectors/fetch_osint.py on branch claude/hopeful-knuth-vr7qp7 of daninthedark/myclaude. Its last run fetched 400 KEV entries, 300 high-severity CVEs, 177 satellites, 104 aircraft and 50 news items.
  • Not built: screens, internal-feed adapters, the link graph, cases, the AI brief.
