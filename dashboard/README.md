# Bilik Situasi Sempadan Malaysia

Dashboard satu halaman tentang pencerobohan sempadan dan penyeludupan di Malaysia.
Setiap angka diambil daripada kenyataan rasmi agensi (JKDM, PDRM, Maritim Malaysia,
AKPS, Imigresen, PGA, ESSCOM) seperti yang dilaporkan Bernama, Berita RTM, NST dan
media lain. Senarai penuh sumber (S1–S15) ada di bahagian bawah halaman.

Buka `index.html` terus dalam pelayar. Tiada build step; hanya Google Fonts dimuat dari luar.

Angka disemak pada 26 Okt 2026.
